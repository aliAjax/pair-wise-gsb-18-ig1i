# hxwl-04 牙科根管治疗 · 根尖手术排程与术后随访看板

按牙位把根管看板接到排程与术后随访：术前影像日期、麻醉结论、显微镜时段一处登记，
术后补录与两周复查结论自动驱动病例在「待排 → 已排 → 待复查 → 复诊/已结案」间流转。

## 业务规则

- **牙位登记**：患者、FDI 两位牙位、术前影像日期、麻醉结论。
- **同一显微镜头同一时段只接一台手术**（日期 + 上午/下午 + 镜号 三者相同即冲突，冲突直接拦住）。
- **影像过期（拍摄超过 30 天）或麻醉未确认/有禁忌 → 留在待排**，不占用显微镜时段；资料补齐后重算。
- **术后补录**：根尖切除长度（mm）、倒充材料、标本编号；**标本编号重复直接拦截**。
- **两周复查**：疼痛未缓解，或骨缺损增大 → 自动转入复诊名单；两者均好转 → 结案。
- 已结案病例释放显微镜头时段；看板顶部有未来 7 天的显微镜占用表。

## 四层分离

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 资料 | `src/domain/types.ts` | 数据结构、状态枚举、常量（影像 30 天、复查 14 天） |
| 判断 | `src/domain/rules.ts` | 纯函数规则：待排原因、时段冲突、标本查重、复查结论（不碰存储与界面） |
| 保存 | `src/storage/` | `CaseRepository` 接口 + localStorage 实现 + 内存实现 + 示例数据 |
| 编排 | `src/app/surgeryService.ts`、`src/app/useBoard.ts` | 把判断与保存接成用例，规则违例抛 `RuleError` |
| 界面 | `src/ui/`、`src/App.tsx` | 看板、登记表单、卡片内联操作、显微镜排期表、通知 |

数据保存在浏览器 localStorage（键 `hxwl-04-apical-board:v1`），右上角「恢复示例数据」可重置。
接后端时只需新增一个 `CaseRepository` 实现，领域规则和界面都不用改。

## 技术栈

React 19 + Vite + TypeScript（严格模式）+ 原生 CSS；测试用 Node 内置 `node:test`，
经 Vite 自带的 esbuild 即时转译，无额外测试框架依赖。
